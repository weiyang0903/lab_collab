INPUT VARIABLES (1-50):
-----------------------
  DIO Level:      1=High, 2=Medium, 3=Low
  DTI Level:      4=High, 5=Medium, 6=Low
  STIA Level:     7=High, 8=Medium, 9=Low
  ETX Level:      10=High, 11=Medium, 12=Low
  Retrans:        13=High, 14=Medium, 15=Low
  RANK Change:    16=Decrease, 17=Increase, 18=Normal
  DROP Rate:      19=High, 20=Medium, 21=Low
  DPR:            22=High, 23=Normal
  PFR:            24=High, 25=Normal
  VN:             26=Forged, 27=Normal
  MSG Flood:      28=Flood, 29=Normal
  SYBIL:          30=Multi, 31=Single
  Bidirectional:  32=Yes, 33=No
  Power Anomaly:  34=High, 35=Normal
  NPC:            36=Low, 37=Medium, 38=High
  NC:             39=Low, 40=Medium, 41=High
  UDP_recv:       42=High, 43=Normal
  PF_rate:        44=Low, 45=Normal

  207=VERIFY_RANK, 208=VERIFY_VERSION

============ SECTION 1: FLSec-RPL RULES [Ref 9] ============

DIO Suppression Attack Detection using Threat Score
Score = DIO_weight + DTI_weight + STIA_weight
  DIO: H=3, M=2, L=1 | DTI: L=3, M=2, H=1 | STIA: L=3, M=2, H=1

Rule 1 (Score=9): DIO=H + DTI=L + STIA=L → MALICIOUS
  Logic: ¬DIO_High ∨ ¬DTI_Low ∨ ¬STIA_Low ∨ MALICIOUS
  CNF:   -1 -6 -9 101 0

Rule 4 (Score=8): DIO=H + DTI=M + STIA=L → MALICIOUS
  CNF:   -1 -5 -9 101 0

Rule 10 (Score=8): DIO=M + DTI=L + STIA=L → MALICIOUS
  CNF:   -2 -6 -9 101 0

Rule 2 (Score=8, STIA≠L): DIO=H + DTI=L + STIA=M → QUARANTINE
  CNF:   -1 -6 -8 102 0

Rule 3 (Score=7): DIO=H + DTI=L + STIA=H → QUARANTINE
  CNF:   -1 -6 -7 102 0

Rule 5 (Score=7): DIO=H + DTI=M + STIA=M → QUARANTINE
  CNF:   -1 -5 -8 102 0

Rule 7 (Score=7): DIO=H + DTI=H + STIA=L → QUARANTINE
  CNF:   -1 -4 -9 102 0

Rule 11 (Score=7): DIO=M + DTI=L + STIA=M → QUARANTINE
  CNF:   -2 -6 -8 102 0

Rule 13 (Score=7): DIO=M + DTI=M + STIA=L → QUARANTINE
